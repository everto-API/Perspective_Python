# Perspective_Python

[Stanford 3D Scanning Repository](https://graphics.stanford.edu/data/3Dscanrep/) used for the .ply arquives

This is a university task where I needed to create a script that read a .ply (3D object analysed) then project the object with projections, translations and Quaternion Rotation.

The repository have 2 .ply examples, one with 3mb and another 500mb;
If you want to explode your computer, I would recommend the 500mb version :D.
